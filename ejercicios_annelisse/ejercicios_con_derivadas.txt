1. EJERCICIO 6.a: f(x) = |x - 2| - 3 en [-1, 5]
   - Archivos:
     * ejercicios_annelisse/ej_ann_06a.py
   - Líneas afectadas: 278, 294
   - Elementos detectados:
     * Derivadas laterales f'_-(2) = -1 != f'_+(2) = +1
     * Mención a "discontinuidad en la derivada" en el vértice angular.
   - Corrección oficial de Precálculo:
     Propiedad de no negatividad del valor absoluto: |x - 2| >= 0.
     Mínimo absoluto natural en x = 2 donde |x - 2| = 0 ==> f(2) = -3.
     Tramos lineales: f(x) = -x - 1 (m = -1 < 0, decreciente en [-1, 2])
     y f(x) = x - 5 (m = 1 > 0, creciente en [2, 5]).

--------------------------------------------------------------------------------

2. EJERCICIO 6.d: f(x) = -|x + 5| - 3 en [-10, -7] (o sqrt(x^2 + 10x + 25))
   - Archivos:
     * ejercicios_annelisse/ej_ann_06d.py
   - Líneas afectadas: 10, 158, 172
   - Elementos detectados:
     * f'(x) = d/dx(-x - 5) = -1 < 0
   - Corrección oficial de Precálculo:
     Identidad modular: sqrt((x + 5)^2) = |x + 5|.
     Para todo x en [-10, -7], se cumple x <= -7 < -5, luego x + 5 < 0.
     Por definición modular: |x + 5| = -(x + 5) = -x - 5.
     Pendiente afín m = -1 < 0 ==> x1 < x2 ==> -x1 - 5 > -x2 - 5 (estrictamente decreciente).
